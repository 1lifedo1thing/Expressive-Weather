# 主な機能

**Expressive Weather** は、Material 3 Expressive の表現力と高い視認性を両立し、各国の公式気象データ・高解像度雨雲レーダー・防災警報を 1 つの Android アプリに統合しています。

---

## 1. Material 3 Expressive UI ＆ アダプティブ背景

- **ダイナミックシェイプ＆モーフィング**: ダッシュボード、Bento 詳細画面、初期セットアップ画面にわたって有機的な Material 3 Expressive シェイプとフロストガラス表現を採用。
- **端末の傾き連動エフェクト**: 端末の傾きセンサーに応じて雨粒・ガラス結露・積雪表現がリアルタイムに変化。
- **昼夜・テーマ連動**: 天候連動テーマ・システム動的カラー・ライト／ダークモードに対応（初期セットアップ画面もライト時は昼の晴れ空、ダーク時は夜の快晴に連動）。
- **スマホ・折りたたみ・タブレット対応**: 端末幅に応じてスマホ 1 ペインとタブレット／折りたたみ 2 ペイン（ナビゲーションレール・2 ペイン設定）へ自動最適化。
- **4 言語対応**: 日本語・英語・簡体字中国語・繁体字中国語に対応し、初期セットアップ画面および設定画面からいつでも切り替え可能。

---

## 2. 雨の降り始め・降り止み予測 ＆ Android 16 Live Updates

- **分単位の降水カウントダウン**: 高解像度ナウキャストと短時間降水予測（`PrecipitationAnalyzer`）を組み合わせ、雨が降り始める／止むまでの残り時間を算出。
- **Android 16 Rich Ongoing Notifications**: ステータスバーやロック画面へ残り時間と状況を表示する Live Updates（`shortCriticalText`）に対応（現在地自動追従は任意）。

---

## 3. マルチリージョン雨雲レーダー ＆ 台風情報

- **日本（気象庁 JMA）**:
  - 250m メッシュ高解像度降水ナウキャスト（HRPNS）
  - 15 時間先までの降水短時間予報
  - キキクル（土砂災害・浸水害・洪水害の危険度分布）
  - 気象衛星ひまわり画像 ＆ 台風進路・予報円オーバーレイ
- **米国（NOAA / IEM）**:
  - NEXRAD / MRMS 反射強度レーダー
  - 外挿ナウキャストおよび HRRR（+18 時間）数値予報レイヤー
- **世界全域（RainViewer）**:
  - 世界中をカバーする広域合成レーダータイルのタイムライン再生
- **ネイティブ地図描画**: Google Maps SDK for Android によるライト／ダーク連動カスタムマップスタイル、多層キャッシュ、滑らかなフレーム再生に対応。

---

## 4. 各地域の防災・気象警報

- **日本**: 気象庁の特別警報・警報・注意報、およびキキクル警戒レベル（1〜5）。
- **米国**: NOAA / 米国国立気象局（NWS）公式のアクティブ警報（CAP / GeoJSON）。
- **欧州**: MeteoAlarm による欧州 39 か国の公式気象警報。
- **世界**: 世界気象機関（WMO）公式警報および国連・欧州委員会 GDACS の大規模災害警報。

---

## 5. 5 種類のホーム画面ウィジェット

| ウィジェット | サイズ | 内容 |
| :--- | :---: | :--- |
| **コンパクト** | 2×2 | 現在の天気・気温・当日の最高／最低気温 |
| **ワイド中（時間別）** | 4×2 | 現在の天気 ＋ 5 時間先までの時間別予報 |
| **ダッシュボード大** | 4×4 | 現在の天気・時間別予報・7 日間の週間予報 |
| **Material Shape** | 2×2 | 有機的な Material 3 Expressive シェイプに気温と天気アイコンを表示 |
| **Material You 雨雲レーダー** | 4×2 | 端末の Material You 配色に調和する雨雲レーダープレビュー ＋ 天気予報 |

---

## 6. プライバシー重視の設計

- 独自バックエンドサーバーなし・アカウント登録不要・広告なし・トラッキング SDK 不使用。
- 位置情報権限を許可せず、都市の手動検索だけでも全機能を利用可能。バックグラウンド位置情報は、アプリ内での明確な事前開示ダイアログを確認したうえでユーザーが任意に有効化する設計です。
- 詳細は [PRIVACY_POLICY.md](../../PRIVACY_POLICY.md) をご覧ください。
